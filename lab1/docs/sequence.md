```mermaid
sequenceDiagram
    actor P as Плательщик
    participant S as Система коммунальных платежей
    participant B as Банк

    P->>S: Открытие системы
    P->>S: Ввод лицевого счёта / адреса
    S->>P: Проверить корректность данных
    S->>S: Получение начислений
    S-->>P: Отображение задолженности и услуг

    P->>S: Выбор услуг и суммы
    P->>S: Выбор способа оплаты
    S->>S: Проверка достаточности средств

    alt Средств недостаточно
        S-->>P: Сообщение об ошибке
        P->>S: Повторная попытка оплаты
    else Средств достаточно
        S->>S: Формирование платёжного поручения
        S->>B: Передача платёжного поручения

        par Проверка реквизитов
            B->>B: Проверка реквизитов платежа
        and Проверка доступности операции
            B->>B: Проверка возможности операции
        end

        alt Платёж успешно выполнен
            B-->>S: Подтверждение платежа
            S->>S: Сохранение информации об операции
            S-->>P: Электронная квитанция
        else Платёж не выполнен
            B-->>S: Сообщение об ошибке
            S-->>P: Ошибка оплаты
            P->>S: Повторная попытка
        end
    end
    ```
