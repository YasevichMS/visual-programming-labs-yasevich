# Лабораторная работа №6. Kodular

## 1. Описание приложения

Реализовано базовое приложение «Приветствие».

### Компоненты Screen1:
- Label1 — заголовок «Maxim»
- TextBox — поле для ввода имени (Hint = «Name»)
- Button — кнопка «Hello»
- Label2 — для вывода результата
- Label3 — с фамилией **Yasevich** (отображается на экране)

### Логика работы:
При нажатии на кнопку «Hello»:
- если текстовое поле пустое → выводится сообщение «Write you name»
- если имя введено → выводится «Hello, <Name>!»

Использованы блоки:
- условный блок `if-then-else`
- проверка `is empty`
- соединение строк `join`

## 5. Ограничения бесплатного тарифа Kodular

При выполнении работы использовался бесплатный тариф. Основные ограничения:
- Максимум 10 проектов
- Размер ассетов до 10 МБ

В рамках базового задания эти ограничения не создали проблем.
