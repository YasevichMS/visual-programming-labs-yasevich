## 1. Предметная область и модель данных

**Предметная область:** Клуб настольных ролевых игр (TTRPG Club) — учёт игроков, кампаний, персонажей и игровых сессий.

### Сущности

| Сущность     | Описание                                      |
|--------------|-----------------------------------------------|
| Игроки       | Участники клуба                               |
| Кампании     | Игровые кампании / приключения                |
| Персонажи    | Игровые персонажи, принадлежащие игрокам      |
| Сессии       | Конкретные игровые встречи                    |

### Свойства сущностей

**Игроки:**
- Имя (Title)
- Уровень опыта (Select: Новичок / Средний / Опытный / Мастер)
- Любимые жанры (Multi-select)
- Активен (Checkbox)

**Кампании:**
- Название (Title)
- Система (Select: D&D 5e, Pathfinder 2e, Call of Cthulhu и др.)
- Статус (Select: Планируется / Идёт / Завершена / На паузе)
- Дата начала (Date)
- Мастер (Relation → Игроки)

**Персонажи:**
- Имя персонажа (Title)
- Класс / Раса (Select / Text)
- Уровень (Number)
- Игрок (Relation → Игроки)
- Кампания (Relation → Кампании)
- Опыт до следующего уровня (Formula)

**Сессии:**
- Название (Title)
- Дата (Date)
- Продолжительность (часы) (Number)
- Кампания (Relation → Кампании)
- Участники (Relation → Игроки, Allow multiple)
- Оценка (Select)
- Заметки (Text)
- Кнопка «Создать следующую сессию» (Button)

### Связи (Relation)

1. Персонаж → Игрок (many-to-one)
2. Персонаж → Кампания (many-to-one)
3. Сессия → Кампания (many-to-one)
4. Сессия ↔ Игроки (many-to-many) — кто присутствовал на сессии
5. Кампания → Игрок (Мастер)

### Формула

В базе «Персонажи» свойство **«Опыт до следующего уровня»**:

```formula
if(prop("Уровень") < 5, 1000, if(prop("Уровень") < 10, 2000, 3000))
```

### Кнопка

В базе «Сессии» добавлена кнопка **«Создать следующую сессию»**, которая создаёт новую запись с датой = сегодня + 7 дней.

## 4. Ачивки

### Ачивка 5: Notion API

Создана интеграция Notion API.

- Получен Internal Integration Token.
- Интеграция подключена к базе данных «Сессии».
- Выполнен запрос через Python-скрипт:

```python
import requests
import json

TOKEN = "ntn_..."
DATABASE_ID = "417e6f90-37ea-8046-bb9e-c0c398e7f323"

headers = {
    "Authorization": f"Bearer {TOKEN}",
    "Notion-Version": "2022-06-28",
    "Content-Type": "application/json"
}

url = f"https://api.notion.com/v1/databases/{DATABASE_ID}/query"
response = requests.post(url, headers=headers, json={})

print("Статус:", response.status_code)
print(json.dumps(response.json(), indent=2, ensure_ascii=False))
```

**Результат:** получен успешный ответ со статусом **200** и полным списком записей базы «Сессии».

Скриншоты запроса, ответа и настроек интеграции приложены в папку `screenshots/`.
