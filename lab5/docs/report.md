# Лабораторная работа №5. Чат-боты

## 1. Выбранный трек

**Трек C — TypeBot.**

## 2. Цель работы

Освоить low-code/no-code платформу TypeBot для создания чат-ботов, научиться проектировать диалоговые сценарии, работать с переменными и условиями, настраивать HTTP-интеграции, изменять оформление и публиковать готового бота.

## 3. Ссылка на чат-бота

Публичная ссылка на созданного чат-бота:

[Открыть чат-бота TypeBot](https://typebot.co/lab5-yasevich-bot-bfxr22u)

## 4. Описание выполненной работы

В качестве основы для разработки был выбран шаблон **Customer Support**. Шаблон был полностью переведён на русский язык и дополнен функциональностью в соответствии с требованиями лабораторной работы.

### 4.1. Русификация шаблона

Все текстовые элементы чат-бота были переведены на русский язык. Были изменены сообщения, подписи кнопок, подсказки в полях ввода и сообщения об ошибках.

После перевода была проверена работоспособность диалогового сценария.

### 4.2. Добавление новых блоков

В сценарий были добавлены следующие элементы:

- Блок ввода имени студента с сохранением введённого значения в переменную `Имя`.
- Блок ввода учебной группы с сохранением значения в переменную `Группа`.
- Финальное сообщение с персонализированным обращением к пользователю.

Добавленные блоки позволяют собирать необходимую информацию и использовать её в дальнейших сообщениях чат-бота.

### 4.3. Работа с переменными

В процессе разработки были созданы и использованы следующие переменные:

- `Имя` — хранит имя студента.
- `Группа` — хранит название учебной группы.
- `Вопрос` — хранит текст вопроса пользователя.

Переменные используются для передачи введённых данных между блоками и формирования персонализированных сообщений.

### 4.4. Реализация условия Condition

В сценарий был добавлен блок `Condition`, обеспечивающий ветвление диалога в зависимости от значения переменной `Группа`.

Реализована следующая логика:

- Если значение переменной соответствует заданному условию, пользователь направляется по первой ветви сценария.
- Если условие не выполняется, пользователь направляется по альтернативной ветви.

Использование условного блока позволяет реализовать разветвлённый диалог и продемонстрировать применение логических условий при проектировании чат-ботов.

### 4.5. Настройка HTTP Request

Для демонстрации интеграции с внешними сервисами был добавлен блок `HTTP Request`.

Настроен HTTP POST-запрос, предназначенный для передачи собранных данных на тестовый endpoint.

В запрос включены следующие данные:

- Имя студента.
- Учебная группа.
- Текст вопроса.
- Адрес электронной почты.

Данная интеграция демонстрирует возможность передачи информации из чат-бота во внешние системы для последующей обработки.

### 4.6. Изменение темы оформления

Во вкладке `Theme` были изменены параметры внешнего вида чат-бота:

- Цветовая схема.
- Аватар чат-бота.
- Оформление диалогового окна.

Изменения позволили адаптировать внешний вид исходного шаблона к тематике студенческого чат-бота поддержки.

### 4.7. Публикация чат-бота

После завершения настройки сценария чат-бот был опубликован.

Для проверки работоспособности был протестирован диалоговый сценарий, включая ввод пользовательских данных и переходы между блоками.

Публичная ссылка позволяет открыть чат-бота и проверить его работу.

### 4.8. Экспорт сценария

Для сохранения результата работы был выполнен экспорт сценария чат-бота в формате JSON.

Экспортированный файл размещён в каталоге `exports/`. Он позволяет сохранить структуру сценария для последующего изучения и использования.

## 5. Использованные AI-промпты

В процессе разработки могут использоваться следующие запросы к ИИ для улучшения сценария чат-бота:

1. «Предложи условие Condition для маршрутизации запросов студентов в зависимости от названия учебной группы».
2. «Напиши финальное сообщение чат-бота с использованием переменных {{Имя}} и {{Группа}}».
3. «Предложи улучшения оформления Theme для студенческого чат-бота поддержки».

Эти запросы помогают проектировать логику диалога, персонализировать сообщения и выбирать подходящее оформление.

## 6. Освоенные блоки и элементы TypeBot

В ходе лабораторной работы были изучены и использованы следующие возможности платформы:

| Элемент | Назначение |
|---|---|
| Text bubble | Вывод текстовых сообщений |
| Buttons | Предоставление пользователю вариантов ответа |
| Text input | Получение текстовых данных от пользователя |
| Variables | Сохранение и использование пользовательских данных |

| Theme | Настройка внешнего вида чат-бота |
| Publish / Share | Публикация и предоставление доступа к чат-боту |
| Export to JSON | Сохранение сценария в формате JSON |

## 9. Ограничения бесплатного тарифа TypeBot

При использовании бесплатного тарифа могут действовать ограничения на количество чатов, доступные функции и возможности рабочего пространства.

К основным ограничениям, которые следует учитывать, относятся:

- Ограничение количества чатов в соответствии с условиями выбранного тарифа.
- Возможное отображение брендинга TypeBot.
- Ограничения на количество участников рабочего пространства.
- Недоступность некоторых расширенных интеграций на бесплатном тарифе.

Для выполнения учебной работы использованных возможностей платформы оказалось достаточно.

## 10. Выводы

В ходе лабораторной работы была освоена платформа TypeBot и создан чат-бот на основе шаблона Customer Support. Были изучены основные принципы low-code/no-code разработки диалоговых сценариев, включая визуальное построение логики взаимодействия с пользователем, работу с переменными, реализацию условного ветвления и настройку интеграций.

Исходный шаблон был русифицирован и дополнен блоками сбора имени студента и учебной группы. Для персонализации ответов были созданы переменные `Имя`, `Группа` и `Вопрос`. С помощью блока `Condition` реализована маршрутизация диалога в зависимости от заданного условия. Также был добавлен блок `HTTP Request` для демонстрации передачи собранных данных во внешнюю систему.

Дополнительно была изменена тема оформления чат-бота, выполнена публикация и подготовлен экспорт сценария в формате JSON. Работоспособность сценария проверялась в процессе тестирования.

В результате работы были получены практические навыки разработки чат-ботов без необходимости написания большого объёма программного кода. TypeBot предоставляет наглядные средства проектирования диалогов, позволяет быстро проверять сценарии и поддерживает интеграцию с внешними сервисами.

Таким образом, поставленная цель лабораторной работы достигнута: изучены основные возможности TypeBot и реализован чат-бот с переменными, условной логикой, настройкой внешнего вида и HTTP-интеграцией.
